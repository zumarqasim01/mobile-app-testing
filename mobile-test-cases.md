# Mobile Application Testing Portfolio

## Project Overview
This document contains sample manual testing scenarios for Android and iOS mobile applications.

## Testing Areas
- App installation and launch
- Login and logout
- UI layout and responsiveness
- Network connectivity
- App permissions
- Notifications
- Background and foreground behavior
- Error handling

## Sample Test Cases
| Test Case ID | Scenario | Expected Result |
|---|---|---|
| MOB-001 | Launch the application | App should open without crashing |
| MOB-002 | Rotate the device, if supported | UI should remain usable |
| MOB-003 | Disable internet and perform an action | App should handle the connection error gracefully |
| MOB-004 | Deny a requested permission | App should handle the denied permission correctly |
| MOB-005 | Send the app to background and reopen it | App should behave as expected |
| MOB-006 | Enter invalid login credentials | Appropriate validation should appear |

## Execution Status
These are sample test cases for practice. Execution results will be recorded after testing an actual application.
